# Portfolio Yska

Sitio estático (HTML, CSS y JS en `index.html`). No necesita build.

## Subir a GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `portfolio`).
2. Sube todo el contenido de esta carpeta a la raíz del repositorio (incluido `.nojekyll`).
3. En el repositorio: Settings > Pages > Build and deployment > Source: "Deploy from a branch".
4. Elige la rama `main` y la carpeta `/ (root)`, y guarda.
5. Espera uno o dos minutos. El sitio queda en `https://TU-USUARIO.github.io/portfolio/`.

## Editar contenido
En `index.html`, busca `const DATA =`. Ahí están las piezas (título, año, descripción en ES/EN), los textos, los juegos y el mail.
Las imágenes grandes van en `img/` y las miniaturas en `thumb/`, con el mismo nombre de archivo.

`pdf/` tiene las dos versiones en PDF.
